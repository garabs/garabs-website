# GARABS Website

Official website for GARABS LLC.

GARABS helps small businesses and entrepreneurs create, organize, and manage their digital presence through clear, practical, and professional technology solutions.

## Website

- Production: https://garabs.com
- Alternative: https://www.garabs.com

## Services

- Website design and development
- Domain registration and configuration
- Professional email setup
- Website maintenance and technical support
- Digital presence consulting

## Technology

This project is built with:

- TanStack Start
- React
- TypeScript
- Vite
- Tailwind CSS
- Vercel

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Deployment

The production website is deployed automatically to Vercel from the `main` branch.
